# Project Layout

Java code is under `src/main/java/io/github/keellam4/oritechextensions/`.

| Path | What's there |
|---|---|
| `paint/` | The paint system: the target registry, cartridge handling, saved colours, syncing to players |
| `paint/targets/` | One class per kind of paintable thing: addons, pipe networks, glass, reactors, accelerators, hangar doors |
| `hangar/` | The Hangar Door Extension block and block entity |
| `guide/` | The guide book item (opens this wiki in Oracle Index) |
| `client/` | Renderers, the paintable block model wrapper, client setup |
| `test/` | Game tests |
| `Config.java` | Config options (`config/oritech_extensions-common.toml`) |

Other files:

| Path | What's there |
|---|---|
| `src/main/resources/assets/minecraft/atlases/blocks.json` | Which Oritech textures get painted versions |
| `src/main/resources/assets/oritech_extensions/textures/colormap/paint/` | The paint palettes |
| `tools/paint/derive_palettes.py` | Builds the palettes from Oritech's textures |
| `wiki/` | This documentation (in-game guide and website) |
| `tools/wiki/` | Builds the website from `wiki/`, including the 3D paint viewer and the animated hangar door |
| `.github/workflows/` | CI, docs and release workflows |
