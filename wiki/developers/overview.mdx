# Developer Docs

This section is for people who want to build, change or bundle the mod. If you just want to play, the [Guide]($intro) has everything you need.

| You want to… | Start here |
|---|---|
| Build the mod or run its tests | [Building and Testing](building) |
| Know which Minecraft versions are supported and how | [Minecraft Versions](versions) |
| Find your way around the code | [Project Layout](project_layout) |
| Make another block paintable | [The Paint System](paint_system) |
| Put the mod in a modpack, change recipes or config | [For Modpack Makers](pack_makers) |
| Add or edit a wiki page | [Writing Docs](writing_docs) |

Bug reports, ideas and pull requests are welcome on [GitHub](https://github.com/keellam4/oritech-extensions). Before opening a pull request, read [CONTRIBUTING.md](https://github.com/keellam4/oritech-extensions/blob/main/CONTRIBUTING.md).

These pages are only on the website. The in-game guide leaves them out.
