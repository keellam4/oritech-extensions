# Vault Upgrades

Upgrades change how much a vault holds and how it moves items. They work in every vault, including Fluid Vaults.

Right-click a vault with an upgrade to install it, or sneak + right-click the vault with an empty hand to open its upgrade screen.

## Capacity

| Upgrade | Each adds |
| --- | --- |
| Steel Capacity Upgrade | ×2 |
| Electrum Capacity Upgrade | ×4 |
| Energite Capacity Upgrade | ×8 |
| Duratium Capacity Upgrade | ×16 |
| Prometheum Capacity Upgrade | ×32 |

Up to five, all of one tier; they add up, so two Electrum upgrades make a vault hold 8 times as much. An upgrade can't come out while the vault holds more than it could without it.

## Other upgrades

- **Void Upgrade:** items that don't fit are deleted instead of backing up. Only items the vault already holds.
- **Pull Upgrade:** pulls the vault's items from inventories on the sides you pick in the upgrade screen.
- **Push Upgrade:** pushes the vault's items into inventories on the sides you pick. Oritech's pipes don't accept pushed items; set the pipe to extract instead.
- **Redstone Upgrade:** the vault gives off a signal as strong as it is full, and a redstone signal pauses Pull and Push.

One of each fits in a vault.
