# Partition Upgrades

A Fluid Silo holds one fluid. Put a partition upgrade in the Silo Controller's upgrade slot to store several.

| Upgrade | Fluids |
| --- | --- |
| None | 1 |
| Partition Upgrade | 4 |
| Advanced Partition Upgrade | 9 |
| Partition Matrix | Any number |

## Using it

- Open the Silo Controller and put the upgrade in its slot. Each fluid gets a row with Limit, Reserve, Lock and Void.
- The upgrade can't come out while the silo holds more than one fluid, but a bigger upgrade can replace it at any time.
- Fluids settle in layers by density, lightest on top.
