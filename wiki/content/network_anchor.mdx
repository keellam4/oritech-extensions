# Network Anchor

Right-click a Cargo Controller or Crafting Terminal with it to keep every block of that network chunk-loaded: the controller, every vault and tank, and Fluid Silos. Breaking the controller drops the anchor and lets the chunks go. Server owners can turn it off with `allowNetworkChunkLoading`.
