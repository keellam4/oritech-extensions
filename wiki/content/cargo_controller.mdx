# Cargo Controller

Placed against a Cargo Wall, it links every touching vault (up to 1,024) into one inventory, Fluid Vaults and Fluid Silos included.

## Using it

- Pipes: connect to the controller instead of each vault. Items go to the vault already holding them, then to one with room, so a full window never jams a pipe.
- Right-click for the terminal: search (@mod searches by mod), sort, filter items or fluids, take and put in items, fill and empty buckets.
