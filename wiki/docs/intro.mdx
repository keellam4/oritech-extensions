# Oritech Extensions

Small add-ons for [Oritech](https://modrinth.com/mod/oritech) on NeoForge 1.21.1.

## Features

- **Hangar Door Extensions** — make Industrial Hangar Doors longer than Oritech's default 3 blocks.
- **Paintable machine addons** — use Color Cartridges on Oritech (and Oritech Things) addon blocks.
- **Paintable standard pipes** — paint whole connected item or fluid pipe networks.
