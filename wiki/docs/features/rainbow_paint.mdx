# Rainbow Color Cartridge

The Rainbow Color Cartridge paints like Oritech's Color Cartridges, but the colour never settles: painted blocks keep blending through red, yellow, green, cyan, blue and pink. Every rainbow block in view shimmers in step, so a rainbow pipe run or reactor reads as one piece.

## Crafting

Shapeless: one each of the **Redstone**, **Industrial**, **Camo**, **Adamant**, **Sculk** and **Fluxite** Color Cartridges gives **6 Rainbow Color Cartridges**, so it costs the same per use as normal paint.

## What it paints

Everything this mod paints, the same way a normal cartridge does:

- [Machine addons and extenders](paintable_addons) (the dropped item stays rainbow)
- [Every pipe network](paintable_pipes), including framed and duct versions
- [Industrial Glass, reactors, accelerators, Metal Beams and Girders, and Pipe Boosters](paintable_structures)

It doesn't paint Oritech's own machines or Industrial Hangar Doors: Oritech paints those itself and has no rainbow. Orange still clears rainbow paint.

## Rules

- **Rainbow is a colour of its own.** With colour-isolated pipes, rainbow pipes only connect to rainbow pipes (and to unpainted ones).
- New blocks take rainbow from their painted neighbours like any other colour.
- Oritech Things addons can't be rainbow yet; they stay in their normal colours.
- The rainbow textures are made from Oritech's default textures, so a resource pack that retextures Oritech changes the other paints but not rainbow. Blocks a modpack makes paintable with tags don't have a rainbow look.
