# Paintable Machine Addons

Oritech Color Cartridges normally only work on large machines. This mod also lets them paint **machine addon blocks** — Oritech's own addons and those from mods built on them (for example Oritech Things).

## How to paint

1. Hold a Color Cartridge.
2. Right-click (or shift-right-click) an addon.
3. One cartridge is used (none in creative).
4. **Orange Machine Paint** removes the colour.

Painted addons keep their colour when broken and placed again. The item tooltip shows the paint.

## Notes

- Painted textures are generated at load time with the same colour swap Oritech uses for machines.
- Some blocks (Extender, Acceptor) only partly recolour because they use their own orange shades.
