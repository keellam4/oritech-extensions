# Paintable Standard Pipes

Color Cartridges can paint **standard item pipes**, **transparent item pipes**, and **standard fluid pipes** (including their connection segments). Transparent and standard item pipes are one network in Oritech, so they are painted together.

## How it works

1. Right-click a standard pipe with a Color Cartridge.
2. The whole connected network of that type is painted.
3. **Orange** clears the network back to the default look.

## Rules

- Colour is **world-only**. Broken pipes always drop unpainted.
- A newly placed standard pipe inherits colour if it touches a same-type painted neighbour of **one** colour. Conflicting neighbours leave it unpainted.
- Item filters and smart splitters keep Oritech's own paint behaviour; network paint does not recolour them.

## Config

| Key | Default | Meaning |
|---|---|---|
| `pipePaintCostMode` | `NETWORK` | `NETWORK` = one cartridge for the whole network; `PER_BLOCK` = one per block |
| `pipePaintIsolation` | `false` | Reserved for a future same-colour connection mode |

## Not yet supported

Framed pipes, duct pipes, and energy pipes.
