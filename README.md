Small add-ons for [Oritech](https://github.com/Rearth/Oritech) on NeoForge. Built for All the Mods 10, and works with plain Oritech.

## Features

- **Hangar Door Extensions**: make Oritech's Industrial Hangar Door longer than 3 blocks (16 by default, configurable). Extensions open, close and paint with the door.
- **Paint more of Oritech**: Color Cartridges also paint machine addons, standard item and fluid pipe networks, Industrial Glass, whole nuclear reactors and whole particle accelerators.
- **Oritech Extensions Guide**: a craftable book that opens this mod's wiki in-game.

## Documentation

## Requirements

| Minecraft | NeoForge | Oritech | GeckoLib |
|---|---|---|---|
| 1.21.1 | 21.1.200+ | 1.2.x | 4.6+ |
| 26.1.2 | 26.1.2.100+ | 2.0 (experimental) | 5.5+ |

These are every Minecraft version Oritech runs on: Oritech has no builds for 1.21.2 to 1.21.11, and its NeoForge builds need 1.21.1 and 26.1.2 exactly. When Oritech adds a version, this mod follows.

Optional on 1.21.1: Oritech Things (its addons become paintable), Oracle Index (in-game wiki). On 26.1, Oritech paints addons itself.
