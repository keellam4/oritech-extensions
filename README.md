# Oritech Extensions

[![Build](https://github.com/keellam4/oritech-extensions/actions/workflows/build.yml/badge.svg)](https://github.com/keellam4/oritech-extensions/actions/workflows/build.yml)

[![CurseForge](https://img.shields.io/badge/CurseForge-oritech--extensions-f16436)](https://www.curseforge.com/minecraft/mc-mods/oritech-extensions)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Small add-ons for [Oritech](https://github.com/Rearth/Oritech) on NeoForge. Built for All the Mods 10, and works with plain Oritech.

## Features

- **Hangar Door Extensions**: make Oritech's Industrial Hangar Door longer than 3 blocks (16 by default, configurable). Extensions open, close and paint with the door.
- **Paint more of Oritech**: Color Cartridges also paint machine addons, standard item and fluid pipe networks, Industrial Glass, whole nuclear reactors and whole particle accelerators.
- **Oritech Extensions Guide**: a craftable book that opens this mod's wiki in-game.

## Documentation

📖 **<https://keellam4.github.io/oritech-extensions/>**

- **Guide** and **Items & Blocks**: how to use everything. Also in-game: craft the guide (Book + Nickel Ingot), or press **H** with [Oracle Index](https://modrinth.com/mod/oracle-index) installed.
- **[Developers](https://keellam4.github.io/oritech-extensions/developers/overview/)**: building, tests, supported Minecraft versions, the paint system, notes for modpack makers, and releasing.

## Requirements

|---|---|---|---|
| 1.21.1 | 21.1.200+ | 1.2.x | 4.6+ |

Optional: Oritech Things (its addons become paintable), Oracle Index (in-game wiki).
